Engineering & R&D

Engine and systems work, outside of shipping Thalassophobia

These are studio R&D projects: reusable Unreal Engine 5 technology built to make future games faster to build, not one-off game code. Screenshots and video for each are being prepared; the write-ups below reflect what was actually built.

Unreal Engine Plugin Framework

A reusable gameplay framework featuring modular systems, reusable components, and scalable architecture, designed to accelerate development across multiple games.

UE5C++Blueprints
Details

Why it exists: Every new project was rebuilding the same gameplay scaffolding: actor components, interfaces, save/load hooks. This framework packages that scaffolding once as a plugin.

Technical challenges:

  • Designing components generic enough to reuse across genres without becoming over-abstracted.
  • Keeping the framework Blueprint-exposable so design work doesn't require touching C++.
  • Versioning the plugin across projects that diverge over time.

Modular AI Framework

A general-purpose AI framework focused on scalable NPC behavior, reusable Behavior Tree tasks, and modular AI architecture.

UE5C++Behavior Trees
Details

Why it exists: Supporting many different AI archetypes (creatures, NPCs, enemies) usually means duplicated Behavior Tree logic per type. This framework separates reusable tasks/services from per-archetype configuration.

Technical challenges:

  • Building Behavior Tree tasks generic enough to serve very different creature types.
  • Keeping the tooling designer-friendly so tuning doesn't require an engineer.
  • Balancing reusability against per-creature performance cost.

Control Rig & Procedural Animation Framework

Reusable procedural animation and Control Rig systems for creatures and characters, including foot placement, locomotion, and dynamic hit reactions.

Control RigAnimationC++Blueprints
Details

Covers:

  • Procedural foot placement
  • Creature locomotion
  • Fish movement
  • Multi-legged creatures
  • Tentacle animation
  • Dynamic hit reactions

Built directly out of Thalassophobia's need for varied, believable sea-creature movement without hand-authoring a full animation set per creature type.

Multiplayer Gameplay Systems

A collection of multiplayer systems developed across various Unreal Engine projects, focused on replication and network-safe gameplay logic.

UE5C++Replication
Details

Focus areas:

  • Replication patterns for shared gameplay state
  • Multiplayer interactions (pickups, shared objectives, environmental triggers)
  • Authority architecture: deciding what the server owns versus what clients can predict
  • Network-safe gameplay systems that hold up under packet loss and host migration
